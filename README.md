# Expense Tracker - Трекер расходов

**Автор:** Анастасия Рослякова

## 📝 Описание программы

Expense Tracker - это десктопное приложение для учета личных финансов с графическим интерфейсом.
Позволяет добавлять расходы, фильтровать их, считать сумму за период и сохранять данные в JSON.

## ✨ Возможности

- ✅ Добавление расходов с суммой, категорией и датой
- ✅ Автоматическая валидация ввода (сумма > 0, корректная дата)
- ✅ Фильтрация по категориям и периоду дат
- ✅ Подсчет общей суммы за выбранный период
- ✅ Сохранение и загрузка данных в JSON
- ✅ Удаление отдельных записей или всех данных
- ✅ Удобный табличный интерфейс

## 🔧 Требования

- Python 3.7 или выше
- Стандартные библиотеки Python (tkinter, json, datetime, os)
